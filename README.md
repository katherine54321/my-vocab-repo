## 📱 移动端应用程序 (PWA) 安装指南

VocabMatrix 具备渐进式 Web 应用（PWA）能力，无需通过应用商店下载，**直接在手机浏览器中即可一键添加到主屏幕**，体验与原生 App 完全一致：

- **iOS (iPhone / iPad - Safari 浏览器)**：
  1. 使用 Safari 访问应用网址；
  2. 点击屏幕底部的 **分享按钮 (⎋)**；
  3. 向上滑动列表，轻点 **『添加到主屏幕 ➕』**；
  4. 点击右上角『添加』，桌面即生成 **VocabMatrix** 原生图标。
- **Android (Chrome / 华为 / 小米等浏览器)**：
  1. 访问网页后，点击顶部提示的 **『📲 添加到主屏幕』** 按钮；
  2. 或点击浏览器右上角菜单 **⋮** -> 选择 **『添加到主屏幕』** 或 **『安装应用』** 即可。

> **App 模式优势**：脱离浏览器地址栏与工具条，全屏沉浸；Service Worker 离线强缓存，弱网或离线随时刷词。

## ✨ 核心功能矩阵

### 1. 34 个具体生活/学科切片 & 9 大分类集群
摒弃宽泛无意义的笼统类别，全量词汇精准收录于 34 个具体的场景切片：
- 🎓 **人文学科**：心理学与心智认知、政治学与公共治理、哲学思想与伦理逻辑、经济金融与商贸投资、法律条文与司法审判
- 🫀 **人类与生理**：人体器官与生理解剖、人类情感与心境体验、性格品质与人格特质、人际社交与家庭亲情
- 🍽️ **食品与餐饮**：饮品茶酒与水饮 (158词)、水果浆果与坚果、蔬菜菌菇与农作物、肉禽蛋类与海鲜水产、餐饮烹饪菜单与调味
- 🏠 **生活与空间**：建筑结构与居住设施、时尚服饰与穿搭鞋包、生产工具机械与材料用品、日常生活习惯与起居作息
- 🗺️ **地理与自然**：地理地名国家城市名胜景点、动物世界鸟类陆海生物、自然生态天气气候宇宙、时间历法时段季节
- ✈️ **出行与文体**：旅行出行交通工具、体育运动健身球类、艺术文学音乐戏剧、影视娱乐传媒资讯、医药健康临床医疗
- 💼 **教育与职场**：学校教育学术科研、职场商务职业发展管理
- 💻 **科技与数理**：计算机AI与信息技术、数理化基础科学与工程规律
- 💬 **语言与核心表达**：语言表达社会沟通、通用高频交互动作、核心性状特征与程度逻辑

### 2. CEFR 难度 × 场景 2D 交叉全景矩阵
- 全局 2D 热力图呈现 14,200 词在 34 场景 × 6 难度（A1、A2、B1、B2、C1、C2）的分布；
- 移动端支持流畅横向触控滚动，首列场景名称自动吸顶冻结（Sticky）；
- 点击任意交叉单元格数字，一键下钻筛选目标词汇。

### 3. 原生移动端底部 Tab 栏 (Bottom Navigation)
- 适配现代移动端与全面屏安全距离（iPhone Home Indicator Safe Area）；
- 4 个核心导航轻触即达：`场景探索`、`难度矩阵`、`抽认卡`、`词汇自测`。

### 4. 触屏优化抽认卡 (Flashcards)
- 支持卡片正反面翻转自测；
- 移动端内置触控滑动手势：**左滑（下一张）/ 右滑（上一张）**，单手刷词极度高效。

### 5. 词汇自测与即时反馈 (Quiz)
- 基于当前选中场景与难度，动态生成 4 选 1 词义测验；
- 包含连击计数（Streak）与得分统计，强化记忆。

## ⚡ 云端架构：GitHub + CDN + 客户端双层缓存

采用现代化 **“云端只读源 $\rightarrow$ CDN 边缘加速 $\rightarrow$ 客户端双层缓存 (Memory + IndexedDB)”** 架构：

```
                ┌───────────────────────────────────┐
                │   GitHub 源码仓库 (只读源)          │
                │   katherine54321/my-vocab-repo    │
                └─────────────────┬─────────────────┘
                                  │ 全球边缘分发
                                  ▼
                ┌───────────────────────────────────┐
                │   jsDelivr 全球高速 CDN 缓存        │
                │   cdn.jsdelivr.net/gh/...         │
                └─────────────────┬─────────────────┘
                                  │ 首次网络获取
                                  ▼
                ┌───────────────────────────────────┐
                │   客户端 Layer 1: Memory Cache    │
                │   (Map<category, words[]>)        │
                ├───────────────────────────────────┤
                │   客户端 Layer 2: IndexedDB 离线库 │
                │   (持久化 14,200 词，离线秒开)      │
                └───────────────────────────────────┘
```

## 💻 本地运行与开发

本应用为标准前端工程，内嵌轻量级多线程本地测试服务器：

### 方式 1：Windows 一键启动
双击运行目录下的 `start_server.bat` 即可启动服务并自动打开浏览器。

### 方式 2：Python 命令行启动
```bash
python server.py 8080
```
- 本机电脑访问：`http://localhost:8080/`
- 同 Wi-Fi 手机访问：`http://你的电脑局域网IP:8080/`（例如 `http://192.168.1.161:8080/`）
